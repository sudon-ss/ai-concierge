# THE CONCIERGE 動作テスト記録（2026-09-19）

## 概要

- 対象: ブラウザ版（PWA + FastAPI）。ローカルで起動したバックエンドを本番と同じSupabaseに接続して実施。テスト用の登録物は「【QA】」を付け、終了時に削除。
- 状態: **カレンダー連携ありのテスト（3章）は未実施**。テスト中に管理者アカウントのGoogle連携トークンが失効済みだったため（後述）、再連携後に実施する。
- 再実行: `cd backend` → `.venv/Scripts/python.exe ../docs/qa/qa_nocal.py`（要ローカルバックエンド起動: `ENABLE_SCHEDULER=false uvicorn main:app --port 8001`）。

## テスト中に起きた副作用（透明性のため）

1. **管理者アカウントのGoogle連携が外れた**: 検証開始時点で管理者のGoogleトークンは既に期限切れ（テスト運用は7日で失効）で、最初のAPI呼び出しの更新失敗を受けて自動削除された。アプリ本来の動作（失効時は削除して再連携を促す）で、次回アプリ使用時にも同じ結果になっていた。再連携が必要。
2. **管理者の会話履歴が消えた**: E1/E2の空メッセージ検証で、上記「高」の不具合（自動リトライによる全削除）が発動した。開発用の会話のみ。
3. 検証用に作った一時ファイル（ログインページ）・タスク・通知設定の変更はすべて削除／復元済み。他ユーザーのデータは読み書きしていない（越権テストは他人のトークンで管理者側のテスト用タスクに触れる形のみ）。
