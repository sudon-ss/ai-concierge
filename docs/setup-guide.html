THE CONCIERGE

はじめての方向け
セットアップ手引き

Googleカレンダーとの連携、スマホからのワンタップ起動、お知らせの受け取り設定、iPhoneカレンダーをお使いの方の移行手順まで。所要時間はおよそ10分です。

始める前に

アプリのURL https://ai-concierge-nu.vercel.app
  • 使用するGmailアドレスを管理者に伝えて、利用登録を済ませておく。現在このアプリはテスト運用中で、登録済みのアドレスからしか連携できません。未登録のままだとGoogleのログイン画面でブロックされます。
  • スマホで設定するのがおすすめです。パソコンでも同じ手順で使えます。
  • iPhoneの方はSafariで開いてください。ホーム画面への追加がSafariから行えます。
はじめに

今できること・できないこと

設定を始める前に、機能の範囲と現時点の制限をご確認ください。読んでおいていただくと、あとで戸惑うことが減ります。

できること

  • 会話（テキスト・音声）でのご予定登録・変更・空き時間確認
  • 候補日の仮押さえ（返事待ちの間、他の予定で埋まらないよう自動でブロック）
  • 1つのアカウント内で複数カレンダーを選び、同時登録・重複のない一覧表示
  • タスク（期限付きのやること）の登録・管理
  • 毎朝のブリーフィングと、ご予定前のリマインダー（要設定・下記参照）

現時点でできないこと・制限があること

機能の制限

Outlook（Microsoft 365）は現在未対応です。設定作業中のため、いましばらくはGoogleカレンダーでご利用ください。

オフラインでは使えません。通信が必要です。

音声入力は対応ブラウザのみです。iPhoneはSafari、AndroidはChromeでお使いください。それ以外のブラウザでは音声入力が使えないことがあります（テキスト入力は問題なく使えます）。

リマインダー・朝のブリーフィングは、設定をしないと届きません。既定ではオフです。設定方法はPart 2でご案内します。

テスト運用にあたってのご留意事項

運用上の注意

Googleの審査がまだ完了していません。そのため連携時に「このアプリはGoogleで確認されていません」という警告画面が表示されます（Part 1で通過方法をご案内します）。開発中の社内アプリとして想定どおりの表示で、不具合ではありません。

7日間操作がないと、Googleとの連携が自動的に切れることがあります。審査完了前の状態に起因する制限です。切れた場合は設定画面から再度「連携する」を押していただくだけで復旧します。なるべく定期的にお使いいただけると発生しにくくなります。

開発中のため、不具合や使いにくい点が見つかることがあります。お気づきの点は、別途ご案内するフィードバックシートにご記入ください。改善に反映していきます。

Part 1

Googleカレンダーをつなぐ

アプリに「あなたのカレンダーを読み書きしてよい」と許可を与える作業です。パスワードをアプリに預けることはありません。

  1. アプリのURLを開く

    上のURLを開くと、金色のはじめるボタンがある画面が出ます。押して進みます。

  2. お立場を選ぶ（STEP 1/3）

    社長役員CFOから選びます。秘書があなたをどう呼ぶかが変わるだけなので、深く悩まず選んで次へを押してください。あとから設定画面で変更できます。

  3. 「カレンダーをご連携」でGoogleの連携するを押す（STEP 2/3）

    Googleのログイン画面に切り替わります。ここで1つ以上つながないと次へ進めません。

  4. 使いたいGoogleアカウントを選ぶ

    複数のアカウントでログインしている場合は、管理者に伝えたアドレスを選んでください。別のアドレスを選ぶとブロックされます。

  5. 「このアプリはGoogleで確認されていません」を通過する

    審査前の社内テストアプリのため、警告画面が出ます。画面左下の詳細を押し、下に出てくる（安全ではないページ）に移動を押してください。

    この警告について

    これはGoogleの審査をまだ受けていない開発中アプリすべてに出る表示で、不具合ではありません。今回は自分たちで作ったアプリだと分かっているため進んで問題ありません。一般公開時には審査を通すのでこの画面は出なくなります。

  6. カレンダーへのアクセスを許可する

    「予定の表示・編集」の許可を求められます。チェックを入れて続行を押すと、アプリに戻ります。

  7. 「参照」と「登録先」のカレンダーを選ぶ

    アプリに戻ると、カレンダー連携の画面に戻ってきます。カレンダーを複数お持ちの方は、ここで選択欄が出ます。

    2つの設定の違い

    参照＝空き時間を探すときに「予定が入っている」とみなすカレンダー。仕事用と個人用の両方を選んでおくと、プライベートの予定に会議を入れられずに済みます。

    登録先＝新しい予定を書き込むカレンダー。複数選ぶと、その全部に同時に登録されます。

    どちらも最大3つまで。カレンダーが1つしかない方はこの欄は表示されません（自動でそのカレンダーが使われます）。

  8. お知らせの時間を決めて完了（STEP 3/3）

    朝のブリーフィングの時刻と、予定の何分前に知らせるかを選び、利用を開始するを押せば設定完了です。

うまくいかないとき

エラーと出たら、まずもう一度

Googleのログイン途中で「エラーが発生しました」と出ることがあります。多くは一時的なもので、もう一度連携するからやり直すと通ります。シークレットウィンドウ／プライベートブラウズでは失敗しやすいので、通常のウィンドウでお試しください。

「アクセスをブロックしました」と出る場合

そのGoogleアドレスがまだ利用登録されていません。使いたいアドレスを管理者に伝えて、登録後にもう一度お試しください。

Part 2

スマホのホーム画面から
ワンタップで開く

アプリストアからのインストールは不要です。ホーム画面にアイコンを置けば、普通のアプリと同じように全画面で起動します。毎回URLを入力する必要はありません。

iPhone・iPad

  1. SafariでアプリのURLを開く
  2. 画面下中央の共有ボタン（□に↑が刺さったマーク）を押す
  3. メニューを下にスクロールしてホーム画面に追加を押す
  4. 名前を確認して右上の追加を押す
注意

Chromeなど他のブラウザからだとこの項目が出ないことがあります。必ずSafariで開いてください。

Android

  1. ChromeでアプリのURLを開く
  2. 右上の︙（三点メニュー）を押す
  3. ホーム画面に追加またはアプリをインストールを押す
  4. 確認画面で追加／インストールを押す

機種によっては画面下部に「アプリをインストール」の案内が自動で出ます。そちらを押しても同じです。

追加したあと

ホーム画面のアイコンから開くと、ブラウザのアドレスバーが消えて全画面になります。ログイン状態も保持されるので、次からはタップするだけで秘書が立ち上がります。

お知らせを受け取る設定（この設定だけは必須です）

アプリを閉じていてもご予定の前にお知らせが届くようにします。この設定をしないと通知は鳴りません。 ホーム画面への追加を済ませてから行ってください。

  1. ホーム画面のアイコンからアプリを開く

    Safariのタブから開いた状態では設定できません。必ずホーム画面のアイコンから起動してください（iPhoneの仕様です）。

  2. PROFILE（設定）→「リマインダー」を開く

    いちばん下に端末へのお知らせという項目があります。

  3. 有効にするを押して、許可する

    「通知を送信します。よろしいですか？」と聞かれるので許可を押します。

  4. テスト通知を送るで確認する

    通知が届けば設定完了です。以降はご予定の前と、毎朝のブリーフィング時刻にお知らせが届きます。

お知らせが届くタイミング

ご予定の前— 設定した分数（既定は5分前）にお知らせします。分数は同じ「リマインダー」欄で変更できます。

毎朝— 設定した時刻に、その日のご予定と期限の近いタスクをまとめてお知らせします。

うまくいかないとき

「有効にする」が押せない— Safariのタブから開いています。ホーム画面のアイコンから開き直してください。

ボタンが見当たらない・許可が出ない— 以前にホーム画面へ追加した方は、一度アイコンを削除してから追加し直してください。

それでも届かない— iPhoneの「設定」→「通知」に THE CONCIERGE があるかご確認ください。無い場合は追加し直しが必要です。

Part 3

iPhoneのカレンダーを
使っている方へ

この秘書はGoogleカレンダーとOutlookに対応しています。iPhone標準の「カレンダー」アプリでiCloudに予定を入れている方は、Googleカレンダー側でも予定が見えるようにする必要があります。方法は3つあります。

方法 向いている人 できること
A. これからGoogleに貯める
おすすめ		 これから本格的に使う人 読み書きとも即時。秘書から予定を入れると、iPhoneのカレンダーアプリにもすぐ出る
B. iCloudを覗き見させる 今の運用を変えたくない人 読み取りのみ。反映は最大1日遅れ。秘書からは書き込めない
C. 今ある予定を一度だけ移す 過去・未来問わず今の予定を丸ごと持っていきたい人 一回きりのコピー（実行時点の予定を過去・未来とも反映）。以降の新規作成分は同期しない

方法A：iPhoneにGoogleアカウントを追加する（おすすめ）

iPhone標準のカレンダーアプリはそのまま使いつつ、予定の保存先だけGoogleに変える方法です。見た目の操作は今までどおりで、裏側がGoogleカレンダーになります。

  1. 設定からカレンダーのアカウント追加画面を開く

    設定 → アプリ → カレンダー → カレンダーアカウント → アカウントを追加

    iOS 17以前の場合は 設定 → カレンダー → アカウント → アカウントを追加 です。お使いのバージョンで表示が違うときは、設定画面の検索窓に「カレンダー」と入れると早く辿り着けます。

  2. Googleを選んでログインする

    秘書アプリで連携したのと同じGoogleアドレスでログインしてください。

  3. 「カレンダー」をオンにする

    メール・連絡先などの一覧が出るので、少なくともカレンダーをオンにして保存します。

  4. 新規予定の保存先をGoogleに変える

    設定 → アプリ → カレンダー → デフォルトカレンダー で、Googleアカウント側のカレンダーを選びます。

    この一手間が肝心です

    ここを変えないと、iPhoneで作った予定はこれまでどおりiCloudに保存され、秘書からは見えないままになります。

方法B：iCloudカレンダーをGoogleに購読させる

iCloudに予定を貯めたまま、Googleカレンダー側から覗くだけの方法です。手軽ですが制約が大きいので、上の方法Aが使えるならそちらをおすすめします。

  1. iPhoneでカレンダーを公開する

    カレンダーアプリ →下部のカレンダー→共有したいカレンダーのⓘ→公開カレンダーをオン→共有リンクをコピー。

  2. GoogleカレンダーにURLで追加する

    パソコンでGoogleカレンダーを開き、左側の他のカレンダーの＋→URLで追加。コピーしたリンクを貼り付けます。先頭が webcal:// の場合は https:// に書き換えてください。

方法Bの制約

読み取り専用です。秘書から予定を入れたり動かしたりはできません。また、Google側への反映は即時ではなく最大1日ほど遅れることがあるため、直前の予定変更が空き時間チェックに反映されない可能性があります。

公開カレンダーのリンクを知っている人は誰でも予定を閲覧できます。仕事の機密予定が入っているカレンダーでは使わないでください。

方法C：今あるiCloudの予定を一度だけ移す

Macをお持ちなら、カレンダーアプリのファイル → 書き出すから直接 .ics ファイルを保存できます（いちばん簡単です）。お持ちでない場合は、以下の手順でiPhoneまたはパソコンから同じものを用意できます。

  1. カレンダーを「公開」にして、共有リンクを取得する

    iPhone・パソコンいずれかで行います。どちらも所要1分程度です。

    iPhoneで行う場合

    1. 「カレンダー」アプリを開き、下部のカレンダーをタップ
    2. 書き出したいカレンダーの右側にあるⓘをタップ
    3. パブリックカレンダーをオンにする
    4. リンクを共有をタップし、コピーを選ぶ

    パソコンで行う場合

    1. icloud.com/calendar を開いてサインイン
    2. 左側のカレンダー名にポインタを合わせ、表示されるⓘ（情報）を選ぶ
    3. パブリックカレンダーをオンにする
    4. コピーを選んでリンクをコピー
  2. コピーしたリンクを書き換えて、ファイルとして保存する

    コピーされるのは webcal://p12-caldav.icloud.com/published/2/… のようなリンクです。メモ帳など好きな場所に一度貼り付け、先頭の webcal:// だけを https:// に手で書き換えてください。

    書き換えたURLをブラウザの新しいタブのアドレス欄に貼り付けてEnterを押すと、.ics ファイルが自動でダウンロードされます。テキストがそのまま画面に表示された場合は、ファイル → 名前を付けて保存（WindowsはCtrl+S）で、拡張子を .ics にして保存してください。

  3. Googleカレンダーに読み込む

    Googleカレンダーの 設定 → インポート/エクスポート → インポート で、保存した .ics ファイルを選び、取り込み先のカレンダーを指定します。

終わったら「パブリックカレンダー」をオフに戻す

オンのままにしておくと、リンクを知っている人なら誰でもその予定を閲覧できてしまいます。.ics ファイルを保存し終えたら、iPhoneまたはiCloud.comの同じ画面でパブリックカレンダーをオフに戻してください（保存済みの .ics ファイルには影響しません）。

仕上げに

方法Cは、書き出した時点でiCloudに入っている予定を過去・未来問わずまとめてGoogleカレンダーへコピーします。ただし一度きりのコピーのため、これ以降iPhone側で新しく作る予定は自動では連携されません。今後の分も秘書に見せ続けたい場合は、あわせて方法Aの設定もしておいてください。

For Administrators

管理者の方へ
メンバーを追加する

新しく使う方が増えたときの作業です。ご利用される方はこの章を読み飛ばしていただいて構いません。

アプリ側の作業は不要です

追加した方がご自身のGoogleアカウントで連携すれば、その方専用のデータ領域が自動で作られます。必要なのは、Googleの利用許可リストに1名を加えることだけです。

  1. Google Cloud Console を開く

    console.cloud.google.com を開き、画面上部でこのアプリのプロジェクトが選ばれているかご確認ください。

  2. 「Google Auth Platform」→「対象」を開く

    以前の画面ではAPIとサービス → OAuth同意画面です。表示が違う場合は、上部の検索窓に「OAuth」と入れると辿り着けます。

  3. 「テストユーザー」の＋ ユーザーを追加を押す

    追加したい方のGmailアドレスを入力して保存します。反映は即時で、審査などの待ち時間はありません。

  4. 本人にURLとこの手引きを渡す

    あとはこの手引きのとおりに進めていただければ使い始められます。

よくある行き違い

登録したアドレスと、本人がログインで選ぶアドレスは一致している必要があります。仕事用と個人用の2つのGoogleアカウントをお持ちの方には、どちらで使うか事前にご確認ください。違うアドレスを選ぶと「アクセスをブロックしました」と表示されます。

テストユーザーは100人まで登録できます。現在の人数であれば余裕があります。

よくある質問
秘書にどう話しかければいいですか？

チャット画面で、人に頼むように書けば伝わります。「来週、田中さんと1時間打ち合わせしたい」「明日の午後空いてる？」「木曜の商談を30分後ろ倒しして」といった具合です。音声入力ボタンからしゃべっても構いません。

勝手に予定を入れられてしまいませんか？

入りません。登録・変更の前に必ず内容を読み上げて確認を取り、「お願いします」などと返して初めて実行します。

「仮押さえ」とは何ですか？

候補日を相手に送ったあと、返事を待つ間に他の予定で埋まってしまうのを防ぐ機能です。候補枠すべてを［仮］付きの予定としてカレンダーに入れておき、日程が決まって本確定すると、選ばなかった枠は自動で消えます。

登録先を3つ選ぶと、予定変更も3つ全部に反映されますか？

反映されます。「30分後ろ倒し」と伝えれば、同じ予定のコピー全部が一緒に動きます。予定一覧の画面でも、同じ予定は1件にまとめて表示されます。

Outlookも使えますか？

アプリ側の対応は済んでいますが、現在Microsoft側の設定作業中です。使えるようになり次第お知らせします。それまではGoogleカレンダーでお使いください。

連携をやめたいときは？

アプリのPROFILE（設定）画面から解除を押してください。あわせてGoogleアカウント側からも取り消したい場合は、Googleアカウントの「セキュリティ」→「サードパーティ製アプリとの連携」から解除できます。

最初の画面に戻ってやり直したい

PROFILE画面をいちばん下までスクロールし、初期セットアップをやり直すを押してください。
