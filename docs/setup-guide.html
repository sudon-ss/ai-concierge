THE CONCIERGE

はじめての方向け
セットアップ手引き

Googleカレンダーとの連携、スマホからのワンタップ起動、iPhoneカレンダーをお使いの方の移行手順まで。所要時間はおよそ10分です。

始める前に

アプリのURL https://the-concierge-delta.vercel.app
  • 使用するGmailアドレスを管理者に伝えて、利用登録を済ませておく。現在このアプリはテスト運用中で、登録済みのアドレスからしか連携できません。未登録のままだとGoogleのログイン画面でブロックされます。
  • スマホで設定するのがおすすめです。パソコンでも同じ手順で使えます。
  • iPhoneの方はSafariで開いてください。ホーム画面への追加がSafariから行えます。
Part 1

Googleカレンダーをつなぐ

アプリに「あなたのカレンダーを読み書きしてよい」と許可を与える作業です。パスワードをアプリに預けることはありません。

  1. アプリのURLを開く

    上のURLを開くと、金色のはじめるボタンがある画面が出ます。押して進みます。

  2. お立場を選ぶ（STEP 1/3）

    社長役員CFOから選びます。秘書があなたをどう呼ぶかが変わるだけなので、深く悩まず選んで次へを押してください。あとから設定画面で変更できます。

  3. 「カレンダーをご連携」でGoogleの連携するを押す（STEP 2/3）

    Googleのログイン画面に切り替わります。ここで1つ以上つながないと次へ進めません。

  4. 使いたいGoogleアカウントを選ぶ

    複数のアカウントでログインしている場合は、管理者に伝えたアドレスを選んでください。別のアドレスを選ぶとブロックされます。

  5. 「このアプリはGoogleで確認されていません」を通過する

    審査前の社内テストアプリのため、警告画面が出ます。画面左下の詳細を押し、下に出てくる（安全ではないページ）に移動を押してください。

    この警告について

    これはGoogleの審査をまだ受けていない開発中アプリすべてに出る表示で、不具合ではありません。今回は自分たちで作ったアプリだと分かっているため進んで問題ありません。一般公開時には審査を通すのでこの画面は出なくなります。

  6. カレンダーへのアクセスを許可する

    「予定の表示・編集」の許可を求められます。チェックを入れて続行を押すと、アプリに戻ります。

  7. 「参照」と「登録先」のカレンダーを選ぶ

    アプリに戻ると、カレンダー連携の画面に戻ってきます。カレンダーを複数お持ちの方は、ここで選択欄が出ます。

    2つの設定の違い

    参照＝空き時間を探すときに「予定が入っている」とみなすカレンダー。仕事用と個人用の両方を選んでおくと、プライベートの予定に会議を入れられずに済みます。

    登録先＝新しい予定を書き込むカレンダー。複数選ぶと、その全部に同時に登録されます。

    どちらも最大3つまで。カレンダーが1つしかない方はこの欄は表示されません（自動でそのカレンダーが使われます）。

  8. お知らせの時間を決めて完了（STEP 3/3）

    朝のブリーフィングの時刻と、予定の何分前に知らせるかを選び、利用を開始するを押せば設定完了です。

うまくいかないとき

エラーと出たら、まずもう一度

Googleのログイン途中で「エラーが発生しました」と出ることがあります。多くは一時的なもので、もう一度連携するからやり直すと通ります。シークレットウィンドウ／プライベートブラウズでは失敗しやすいので、通常のウィンドウでお試しください。

「アクセスをブロックしました」と出る場合

そのGoogleアドレスがまだ利用登録されていません。使いたいアドレスを管理者に伝えて、登録後にもう一度お試しください。

Part 2

スマホのホーム画面から
ワンタップで開く

アプリストアからのインストールは不要です。ホーム画面にアイコンを置けば、普通のアプリと同じように全画面で起動します。毎回URLを入力する必要はありません。

iPhone・iPad

  1. SafariでアプリのURLを開く
  2. 画面下中央の共有ボタン（□に↑が刺さったマーク）を押す
  3. メニューを下にスクロールしてホーム画面に追加を押す
  4. 名前を確認して右上の追加を押す
注意

Chromeなど他のブラウザからだとこの項目が出ないことがあります。必ずSafariで開いてください。

Android

  1. ChromeでアプリのURLを開く
  2. 右上の︙（三点メニュー）を押す
  3. ホーム画面に追加またはアプリをインストールを押す
  4. 確認画面で追加／インストールを押す

機種によっては画面下部に「アプリをインストール」の案内が自動で出ます。そちらを押しても同じです。

追加したあと

ホーム画面のアイコンから開くと、ブラウザのアドレスバーが消えて全画面になります。ログイン状態も保持されるので、次からはタップするだけで秘書が立ち上がります。

リマインダーについて

今のところ、アプリを開いている間だけ鳴ります

予定前のお知らせは、アプリを開いている状態で画面に出る仕組みです。アプリを閉じている間にスマホへ通知を飛ばす機能はまだ入っていません。

そのぶん、リマインダーをオンにしている間は画面が自動で暗くならないようにしてあります。会議前に開いたまま置いておけば見逃しません。

Part 3

iPhoneのカレンダーを
使っている方へ

この秘書はGoogleカレンダーとOutlookに対応しています。iPhone標準の「カレンダー」アプリでiCloudに予定を入れている方は、Googleカレンダー側でも予定が見えるようにする必要があります。方法は3つあります。

方法 向いている人 できること
A. これからGoogleに貯める
おすすめ		 これから本格的に使う人 読み書きとも即時。秘書から予定を入れると、iPhoneのカレンダーアプリにもすぐ出る
B. iCloudを覗き見させる 今の運用を変えたくない人 読み取りのみ。反映は最大1日遅れ。秘書からは書き込めない
C. 過去分を一度だけ移す これまでの予定も持っていきたい人 一回きりのコピー。以降は同期しない

方法A：iPhoneにGoogleアカウントを追加する（おすすめ）

iPhone標準のカレンダーアプリはそのまま使いつつ、予定の保存先だけGoogleに変える方法です。見た目の操作は今までどおりで、裏側がGoogleカレンダーになります。

  1. 設定からカレンダーのアカウント追加画面を開く

    設定 → アプリ → カレンダー → カレンダーアカウント → アカウントを追加

    iOS 17以前の場合は 設定 → カレンダー → アカウント → アカウントを追加 です。お使いのバージョンで表示が違うときは、設定画面の検索窓に「カレンダー」と入れると早く辿り着けます。

  2. Googleを選んでログインする

    秘書アプリで連携したのと同じGoogleアドレスでログインしてください。

  3. 「カレンダー」をオンにする

    メール・連絡先などの一覧が出るので、少なくともカレンダーをオンにして保存します。

  4. 新規予定の保存先をGoogleに変える

    設定 → アプリ → カレンダー → デフォルトカレンダー で、Googleアカウント側のカレンダーを選びます。

    この一手間が肝心です

    ここを変えないと、iPhoneで作った予定はこれまでどおりiCloudに保存され、秘書からは見えないままになります。

方法B：iCloudカレンダーをGoogleに購読させる

iCloudに予定を貯めたまま、Googleカレンダー側から覗くだけの方法です。手軽ですが制約が大きいので、上の方法Aが使えるならそちらをおすすめします。

  1. iPhoneでカレンダーを公開する

    カレンダーアプリ →下部のカレンダー→共有したいカレンダーのⓘ→公開カレンダーをオン→共有リンクをコピー。

  2. GoogleカレンダーにURLで追加する

    パソコンでGoogleカレンダーを開き、左側の他のカレンダーの＋→URLで追加。コピーしたリンクを貼り付けます。先頭が webcal:// の場合は https:// に書き換えてください。

方法Bの制約

読み取り専用です。秘書から予定を入れたり動かしたりはできません。また、Google側への反映は即時ではなく最大1日ほど遅れることがあるため、直前の予定変更が空き時間チェックに反映されない可能性があります。

公開カレンダーのリンクを知っている人は誰でも予定を閲覧できます。仕事の機密予定が入っているカレンダーでは使わないでください。

方法C：これまでの予定を一度だけ移す

  1. パソコンでiCloud.comからカレンダーを書き出す

    iCloud.comのカレンダーを開き、対象カレンダーを共有設定から公開して、そのリンクをブラウザで開くと .ics ファイルが手に入ります。Macをお使いなら、カレンダーアプリの ファイル → 書き出す のほうが簡単です。

  2. Googleカレンダーに読み込む

    Googleカレンダーの 設定 → インポート/エクスポート → インポート で .ics を選び、取り込み先のカレンダーを指定します。

仕上げに

方法Cは過去分のコピーです。これから作る予定も秘書に見せたい場合は、あわせて方法Aの設定もしておいてください。

よくある質問
秘書にどう話しかければいいですか？

チャット画面で、人に頼むように書けば伝わります。「来週、田中さんと1時間打ち合わせしたい」「明日の午後空いてる？」「木曜の商談を30分後ろ倒しして」といった具合です。音声入力ボタンからしゃべっても構いません。

勝手に予定を入れられてしまいませんか？

入りません。登録・変更の前に必ず内容を読み上げて確認を取り、「お願いします」などと返して初めて実行します。

「仮押さえ」とは何ですか？

候補日を相手に送ったあと、返事を待つ間に他の予定で埋まってしまうのを防ぐ機能です。候補枠すべてを［仮］付きの予定としてカレンダーに入れておき、日程が決まって本確定すると、選ばなかった枠は自動で消えます。

登録先を3つ選ぶと、予定変更も3つ全部に反映されますか？

反映されます。「30分後ろ倒し」と伝えれば、同じ予定のコピー全部が一緒に動きます。予定一覧の画面でも、同じ予定は1件にまとめて表示されます。

Outlookも使えますか？

アプリ側の対応は済んでいますが、現在Microsoft側の設定作業中です。使えるようになり次第お知らせします。それまではGoogleカレンダーでお使いください。

連携をやめたいときは？

アプリのPROFILE（設定）画面から解除を押してください。あわせてGoogleアカウント側からも取り消したい場合は、Googleアカウントの「セキュリティ」→「サードパーティ製アプリとの連携」から解除できます。

最初の画面に戻ってやり直したい

PROFILE画面をいちばん下までスクロールし、初期セットアップをやり直すを押してください。
